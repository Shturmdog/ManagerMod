\# ManagerMod



Простая веб-система для управления небольшим рестораном/кафе. Разработана на Flask с использованием SQLite. Поддерживает 4 роли: администратор, менеджер, повар и официант.



\## Возможности



\- \*\*Ролевая модель\*\* — разные права доступа для каждой должности

\- \*\*Управление заказами\*\* — создание, готовка, завершение

\- \*\*Меню с утверждением\*\* — повар предлагает блюда, менеджер утверждает

\- \*\*Рабочие смены\*\* — открытие/закрытие смены с автоматическим расчётом статистики

\- \*\*Веб-доступ\*\* — работает из любого браузера на любом устройстве



\## Роли и функции



| Роль | Что может делать |

|------|------------------|

| \*\*Администратор\*\* | Создавать и удалять учётные записи сотрудников |

| \*\*Менеджер\*\* | Утверждать/отклонять блюда, открывать и закрывать смены, смотреть статистику выручки |

| \*\*Повар\*\* | Смотреть заказы, менять статус готовки, создавать новые блюда, включать/отключать их доступность |

| \*\*Официант\*\* | Создавать заказы (столик + блюда), отслеживать статус, отмечать заказ как выполненный |





\## Целевая аудитория



Небольшие рестораны и кафе, которым нужна простая, бесплатная система без сложной установки и обслуживания.
